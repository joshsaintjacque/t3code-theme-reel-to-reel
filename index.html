02 · Specifications

What moves, and why

Every animation is tied to real app state. If nothing is running, nothing moves.

01WORKING

Twin reels

Two reels sit in an aluminium deck plate in the left margin, a full supply pack and a smaller take-up. While a turn runs they turn at different speeds and tape runs past the head. They stop where they are.

02WORKING

VU meters

Two amber meters in the right margin. For the first seven seconds of a turn the needles swing hard, then they drop to a low, slow sway so a long turn never nags at the corner of your eye. A REC lamp stays lit throughout.

03DONE

Thump and settle

When the turn ends the needles fall to the stop and bounce off it, the REC lamp goes out and the ladder drops back to its pilot LED. It only plays when a turn actually ends.

04WORKING

LED ladder

The header is a brushed aluminium faceplate. A 16-segment amber ladder climbs with the opening burst, then settles to a low level. At rest, one pilot LED.

05BACKGROUND

Busy threads

A busy thread in the sidebar gets a tape stripe that steps down its edge. If only a background thread is running, just the right meter stirs.

06WORKING

Sprocket row

The live Working… row runs a line of sprocket holes along its foot, stepping like film in a gate.

07FOCUS

Composer bezel

The message box is a recessed slot in an aluminium bezel. Focus it and the bezel lights amber.

08NARROW

Docked deck

No room beside the chat? A small dock with mini reels and meters sits under Settings at the foot of the sidebar, in flow, so it can never sit behind a thread title.

09REDUCED MOTION

A good still

With reduced motion on, the reels stand still and the needles hold a low mid-scale pose. Nothing animates.

05 · Setup

Install

One JSON file. Paste it into T3 Code, or set it from the terminal.

01Copy the JSON

Copy the theme, then in T3 Code open Settings › Appearance › Add theme and paste.

02Or download it

Save reel-to-reel.json and choose it in Add theme.

Download reel-to-reel.json

03Or use the CLI

Fetch the file and set it as the environment theme. Every connected client switches.

curl -fsSL -o reel-to-reel.json https://joshsaintjacque.github.io/t3code-theme-reel-to-reel/reel-to-reel.json
~/.t3/bin/t3 theme set reel-to-reel.json
